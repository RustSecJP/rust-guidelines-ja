# FAQ {#faq}

## どうすれば貢献できますか？ {#how-can-i-contribute}

[GitHub のページ](https://github.com/microsoft/rust-guidelines) に行き、issue か PR を作成してください。新しいガイドラインは
[メタ設計原則](../guidelines/#meta-design-principles) に沿っている必要があります。

<!-- markdownlint-disable-next-line no-trailing-punctuation -->
## あるガイドラインに同意できません…… {#i-disagree-with-a-guideline-}

間違いや問題を見つけたら、[知らせてください](https://github.com/microsoft/rust-guidelines)。また、_must_ のガイドラインが正当なユースケースの
妨げになる場合も知らせてください。_should_ のガイドラインに同意できない場合、普通は私たちがドキュメント化していない正当な例外があります。_should_ のガイドラインが
一般に悪い結果につながると思う場合は、知らせてください。
